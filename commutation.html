Three distinct properties
Reversibility: a decoder can recover the original text from each correct nesting.
Commutation: A(B(X)) equals B(A(X)) character for character.
Path independence: stronger behavioral equivalence must be defined against a specified observable, not inferred from successful decoding.
Interpretive constraint
In this literal delimiter codec, distinct operators generally do not commute. Both routes can still recover X. If two operators are identical, they trivially commute; equivalence beyond text requires a separately specified semantics.
