## Bound 009 — compound operators and reverse unwind

[Open the nested composition laboratory](composition.html).

Build the pipeline from three directional operators in the order **square → curly → round**. Each operator can face forward or reversed, yielding eight orientation combinations. The experiment wraps each output with the next selected delimiter and then **unwinds round → curly → square**, validating the matching opening/closing characters before stripping each exact outer layer.

```text
X → B(X) → C(B(X)) → T(C(B(X)))
                          |
                   undo T first
                   undo C second
                   undo B last
                          |
                          X
```

The syntax codec uses exact delimiter wrapper/unwrapper pairs. It does **not** implement actual compression, data decompression, or physical release. The inverse orientation is displayed as the inverse operator name; the undo action is a validated unwrapping of the layer that was actually encoded. This matters: applying the opposite delimiter as another wrapper is not mathematically identical to undoing the original wrapper.

Automated tests cover all eight direction choices across seven sample payloads (56 round trips), inverse-map properties, mismatch rejection, and the fixed `{{i}}` witness. Daughter 3 maps to literary Circle IX while registers 8/9 remain reserved.

## Bound 010 — path independence versus commutation

[Open the commutation test matrix](commutation.html).

Given two directional text wrappers A and B, test exact equality of `A(B(X))` and `B(A(X))`, and separately decode both in reverse order. The six selected wrappers form a 6×6 comparison matrix:

- Each of the six diagonal pairings commutes trivially.
- All 30 off-diagonal pairs differ in their encoded form for this specific codec, even when the original X can be recovered from both.
- A correct unwind of either ordering returns X exactly. **Reversibility is not commutativity.**
- Tests span five payloads, 36 ordered pairs, both recovery routes, and a mismatch rejection check.
- All judgments are about literal text encoding, not physical operators, Gnostic doctrine, or a quantum spinor experiment.

Dante `{{i}}` stays fixed at zero, Virgil guides, Daughter 3 remains at literary Circle IX, and soul IN/OUT registers 8/9 remain reserved.

## Bound 011 — preserve the ordered path

[Open the SHA-256 path provenance laboratory](provenance.html).

The same original payload can be restored from two noncommuting operator compositions, but the **order of the operations remains material**. Each transformation is represented by a canonical, SHA-256 hashed record containing its parent hash, input, output, direction/operator, stage, path, and the frozen `{{i}}` witness.

- Compare A(B(X)) and B(A(X)) using all six directional delimiters.
- Verify both reversible paths restore the source exactly.
- Compare the ordered terminal hash chains, which distinguish the recorded histories.
- Perform independent hash-chain verification and an automated single-record tamper test.
- Export the browser-session ledger as JSON for later independent inspection.

The reference implementation uses browser Web Crypto SHA-256 on HTTPS, with no server, login or external JavaScript dependency. It does not persist data beyond the current page session until explicitly exported. The hash chain is a consistency mechanism, not trusted timestamping, cryptographic authorship proof, permanent provenance, or a real-world compression/release mechanism. It cannot stop a party from replacing an entire ledger and its published hash when there is no separately trusted anchor.

Dante `{{i}}` stays at zero; Virgil is the guide; Daughter 3 is literary Inferno Circle IX, distinct from reserved soul-out register 9.
