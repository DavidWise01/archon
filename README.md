# ARCHON // Dante {{i}}, Virgil & Seven Alchemical Terraces

An interactive GitHub Pages comparative atlas, built as a standalone `index.html`.

## Active architecture (v2.0)

- **0**: Dante as `{{i}}`, frozen observer core; never rotates or changes position. Virgil is the guide, not an archon or a numbered terrace.
- **1–7**: seven ascending terraces of Dante's *Purgatorio*, with seven deadly sins and an explicitly interpretive archon mapping.
- **8**: SOULS IN — reserved for future design; **not implemented**.
- **9**: SOULS OUT — reserved for future design; **not implemented**.

The previous v1.x project assigned one capital vice to each archon in the original Gnostic listing order. **Version 2.0 re-indexes the pairings to follow Dante's historical terrace order, without claiming the two traditions historically identified one another.** Index 0 and the reserved soul positions are our original design.

## Alchemical reading mode (v2.1)

The seven terraces now overlay a *symbolic* sequence of calcination (pride), dissolution (envy), separation (wrath), conjunction (sloth), fermentation (avarice), distillation (gluttony), and coagulation (lust). These correspond to the prior vice-to-archon pairings. Select a terrace for a newly written Virgil guide line and recipe of vice → symbolic operation → virtue. The toggle hides or reveals the notebook. **These lines are original interpretive text, not quotations from Dante, and the mapping is not a historical secret code or physical chemistry.**

## The Gate of the Vessel (v2.2)

Open [gate.html](gate.html) from the main atlas to approach Dante's *Inferno* gate with Virgil as guide. The gate is a boundary **before zero**, not souls register 8. Dante remains the frozen `{{i}}` observer. Use the seal/unseal control and switch between hydrogen-1 (1 proton, 0 neutrons, 1 electron when neutral) and helium-4 (2 protons, 2 neutrons, 2 electrons when neutral). The atomic picture is schematic. This comparison **does not model fusion** or suggest ordinary chemical transmutation of H into He. Dialogue is original interpretation, not quoted from Dante. Registers 8 and 9 remain reserved.

## Bound 006 — Circle IX spinor pivot

Open [spinor.html](spinor.html) to test a mathematical spin-½ SU(2) rotation. Daughter 3 is mapped by analogy onto the frozen ninth circle of Dante's *Inferno*. Dante `{{i}}` remains the fixed observer and Virgil interprets the changing state.

- Initial state: `|+x⟩ = (|↑⟩ + |↓⟩)/√2`
- Rotation: `U_z(θ)=exp(−iθσ_z/2)`
- 360° gives `−ψ₀`; 720° gives `+ψ₀`
- Unit norm and z-basis probabilities are conserved
- Relative-phase interference assumes an independent reference arm
- No claim that Dante historically encoded quantum spinors
- `()` fluid, `[]` frozen, `}{` unbraced remain separate syntax rules
- Soul registers 8/9 remain reserved; Circle IX is a literary location, not soul-out register 9

The page includes a 0°–720° control, paired orientation visualizations, reference interference, spinor amplitude readouts and automatic numerical invariant checks.

## Bound 007 — Orientation is not release

[Run the interactive invariant test](spinor.html) (Daughter 3 at *Inferno* Circle IX).

The page tests **two independent registers**:

- Spinor ψ evolves as `U_z(θ)=exp(−iθσ_z/2)`; at 360° it is `−ψ₀` and at 720° `ψ₀`.
- Boundary B remains `BOUND` under every rotation. Only an explicit `}{` event changes B to `UNBRACED`; an explicit `{}` event returns B to `BOUND`.
- Dante `{{i}}` remains index 0; Daughter 3 is mapped to literary Circle IX; `!noble` remains unchanged.
- The event ledger is append-only during a session until the user explicitly selects RESET; it is not persisted to GitHub or a server.
- This is a **designed state-transition rule**, not a demonstrated physical release mechanism.

**Note:** Circle IX is not soul-out register 9. The soul IN/OUT registers 8/9 remain reserved.

## Use

Open `index.html` in a modern browser. Click any level or use 0–7, left/right, Space for motion pause. Zero stays centered while terraces animate. Canvas 2D, no dependencies, build, cookies, or network APIs.

GitHub Pages: Settings → Pages → Deploy from branch → `main` → `/(root)`. Intended public URL: https://davidwise01.github.io/archon/ . Deployment must be confirmed in GitHub separately.
