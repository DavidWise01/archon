Invariant statement
 STATE X (literal source, untouched)
   |
   +-- PATH 1  B → A  → UNWIND → X
   |       event 0 : parent = GENESIS
   |       event 1 : parent = hash(event 0)
   |       event 2 : parent = hash(event 1)
   |
   +-- PATH 2  A → B  → UNWIND → X
           event 0 : parent = GENESIS
           event 1 : parent = hash(event 0)
           event 2 : parent = hash(event 1)

  H(event) = SHA256(canonical(event data + parent hash))
  Exact recovery: X' = X    [for each path]
  Identity:       {{i}} = 0 [unchanged]
  Distinction:    history 1 != history 2 [if A != B]
  Conservation:   do not collapse differently ordered paths
The check uses SHA-256 provided by the browser’s Web Crypto API, normally available on HTTPS GitHub Pages. Hashes are deterministic for this page’s canonical JSON field ordering. The same path and payload reproduce the same hash. This is **integrity bookkeeping**, not a proof that real physics, information loss, time, or an actor’s identity is being cryptographically secured.
